# Complete Example — Power Platform Environment

This example demonstrates a fully-configured Power Platform environment with Dataverse, Managed Environment governance, and an application admin assignment.

It creates:
- A Sandbox environment with Dataverse database
- A Managed Environment with solution checker in Warn mode
- Restricted canvas app sharing (ExcludeSharingToSecurityGroups)
- An optional service principal assigned as System Administrator
- Environment settings with customized audit and feature configuration
